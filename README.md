# HealthyBite
เว็บไซต์สั่งอาหารสุขภาพออนไลน์ เลือกเมนู ใส่ตะกร้า ใช้โค้ดส่วนลด และชำระเงินได้ครบขั้นตอน
สร้างด้วย Next.js (App Router) + TypeScript และ deploy บน Vercel

## รายชื่อสมาชิก
1. นายนวดล ทัศนา (6804101354)
2. นางสาวพิมหทัย ปาลี (6804101364)
3. นางสาววรรณวิลัย เรืองนาค (6804101376)
4. นางสาววริศรา ปานทะยักษ์ (6804101382)
5. นางสาววิมลสิริ เกวี (6804101385)

## ฟีเจอร์
- **หน้าแรก:** โปรโมชั่นประจำเดือน เมนูยอดฮิต รีวิวจากลูกค้า รีวิวล่าสุด และ footer
- **สั่งซื้อ:** ดึงเมนูจาก API ภายนอก ชื่อเมนูแปลเป็นภาษาไทย กดที่การ์ดเพื่อดูส่วนผสมและรายละเอียด
- **เข้าสู่ระบบด้วย Google:** ต้องเข้าสู่ระบบก่อนจึงจะสั่งอาหาร ดูตะกร้า และดูโปรไฟล์ได้
- **ตะกร้า:** สรุปรายการ → เลือกวิธีชำระเงิน → หน้า "การชำระเงินเสร็จสิ้น"
- **วิธีชำระเงิน:** พร้อมเพย์ (QR), บัตรเครดิต/เดบิต (ฟอร์มกรอกข้อมูล), เก็บเงินปลายทาง
- **โค้ดส่วนลด:** `HEALTHY10` ลด 10%, `WELCOME50` ลด 50 บาท (ขั้นต่ำ 200), `FREESHIP` ส่งฟรี
- **โปรไฟล์:** แสดงรูปและชื่อจาก Google พร้อมกรอกที่อยู่และเบอร์โทรศัพท์
- **รีวิว:** ลูกค้าที่เข้าสู่ระบบเขียนรีวิวและให้ดาวได้ เจ้าของร้านลบรีวิวได้
- **ป๊อปอัพแจ้งเตือน:** ใช้ป๊อปอัพของเว็บแทน alert ของเบราว์เซอร์

## เทคโนโลยีที่ใช้
- **Framework:** Next.js 14 (App Router), React 18, TypeScript
- **เข้าสู่ระบบ:** Auth.js (next-auth v5) + Google OAuth
- **ข้อมูลเมนู:** [TheMealDB API](https://www.themealdb.com/api.php)
- **แปลภาษา:** [MyMemory Translation API](https://mymemory.translated.net/)
- **เก็บรีวิว:** Upstash Redis (ไม่บังคับ ถ้าไม่ตั้งจะเก็บในหน่วยความจำชั่วคราว)
- **Hosting:** Vercel

## ที่มาของ API และข้อมูล

| แหล่งข้อมูล | ใช้ทำอะไร | ผู้ให้บริการ | ค่าใช้จ่าย |
|---|---|---|---|
| [TheMealDB API](https://www.themealdb.com/api.php) | รายการเมนู รูปอาหาร ส่วนผสม หมวดหมู่ และประเทศต้นทางของเมนู | TheMealDB (ฐานข้อมูลสูตรอาหารแบบเปิด) | ฟรี ใช้คีย์ทดสอบเลข `1` |
| [MyMemory Translation API](https://mymemory.translated.net/) | แปลชื่อเมนู ชื่อประเทศ และชื่อส่วนผสมเป็นภาษาไทย | Translated | ฟรี มีโควตาตัวอักษรต่อวัน |
| [Google OAuth 2.0](https://developers.google.com/identity/protocols/oauth2) | เข้าสู่ระบบ ดึงชื่อ อีเมล และรูปโปรไฟล์ | Google | ฟรี |
| [Upstash Redis](https://upstash.com/) | เก็บรีวิวถาวร (ไม่บังคับ) | Upstash | มีแผนฟรี |

### API ของ TheMealDB ที่เรียกใช้

| ไฟล์ในโปรเจกต์ | Endpoint | ข้อมูลที่ได้ |
|---|---|---|
| `src/app/api/menu/route.ts` | `filter.php?c=Vegetarian`, `Seafood`, `Chicken` | รหัสเมนู ชื่อ และรูป ของแต่ละหมวด (หมวดละ 6 เมนู) |
| `src/app/api/menu/[id]/route.ts` | `lookup.php?i=<รหัสเมนู>` | หมวด ประเทศต้นทาง ส่วนผสมและปริมาณ |

เซิร์ฟเวอร์ของเราเป็นผู้เรียก API ภายนอกและเก็บผลไว้ในแคช (รายการเมนู 1 ชั่วโมง คำแปล 7 วัน) เพื่อลดจำนวนครั้งที่เรียกและไม่ให้เกินโควตา

### ข้อมูลที่เว็บสร้างเอง ไม่ได้มาจาก API
- **ราคาอาหาร:** เป็นราคาสมมติ คำนวณจากรหัสเมนู
- **โปรโมชั่นรายเดือนและโค้ดส่วนลด:** กำหนดไว้ในโค้ด
- **รีวิวตัวอย่าง 10 รายการ:** เขียนไว้ในโค้ด ส่วนรีวิวที่ลูกค้าเขียนจะถูกบันทึกผ่าน `/api/reviews`

### เงื่อนไขการใช้งานข้อมูล
- เมนู รูปภาพ และส่วนผสมเป็นสูตรอาหารจาก TheMealDB ไม่ใช่เมนูจริงของร้าน
- เว็บนี้ใช้คีย์ทดสอบของ TheMealDB ซึ่งอนุญาตให้ใช้ระหว่างพัฒนาและเพื่อการศึกษา หากเผยแพร่ใช้งานจริงในวงกว้าง ต้องสมัครเป็นผู้สนับสนุน (supporter) ของ TheMealDB ตามเงื่อนไขของผู้ให้บริการ
- ชื่อภาษาไทยเป็นการแปลด้วยเครื่อง อาจไม่ถูกต้องทุกชื่อ

## วิธีติดตั้ง
ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18.17 ขึ้นไป

```bash
# 1. ติดตั้งแพ็กเกจ
npm install

# 2. สร้างไฟล์ตั้งค่า แล้วกรอกค่าตามหัวข้อถัดไป
cp .env.example .env.local

# 3. รันโหมดพัฒนา
npm run dev
```

เปิด http://localhost:3000

### ตั้งค่า `.env.local`
```env
AUTH_SECRET=           # สร้างด้วยคำสั่ง: openssl rand -base64 32
AUTH_GOOGLE_ID=        # จาก Google Cloud Console
AUTH_GOOGLE_SECRET=    # จาก Google Cloud Console

# ไม่บังคับ
NEXT_PUBLIC_ADMIN_EMAIL=            # อีเมล Google ของเจ้าของร้าน (ใช้ลบรีวิว)
UPSTASH_REDIS_REST_URL=             # เก็บรีวิวถาวร
```
> หลังแก้ `.env.local` ต้องหยุดแล้วรัน `npm run dev` ใหม่ทุกครั้ง

### สร้าง Google OAuth Client
1. เข้า [Google Cloud Console](https://console.cloud.google.com/) แล้วสร้างหรือเลือกโปรเจกต์
2. ไปที่ **APIs & Services → OAuth consent screen** เลือก External กรอกชื่อแอปและอีเมล แล้วเพิ่มอีเมลผู้ทดสอบใน **Test users**
3. ไปที่ **Credentials → Create Credentials → OAuth client ID** เลือก **Web application**
4. **Authorized JavaScript origins:** `http://localhost:3000`
5. **Authorized redirect URIs:** `http://localhost:3000/api/auth/callback/google`
6. คัดลอก Client ID และ Client secret ไปใส่ใน `.env.local`

### QR พร้อมเพย์
นำรูป QR พร้อมเพย์ของร้านไปวางที่ `public/qr.png` (ถ้าไม่มีโฟลเดอร์ `public` ให้สร้างใหม่ได้เลย)

## วิธีใช้งาน
1. เปิดหน้าแรก ดูโปรโมชั่นและเมนูยอดฮิต
2. กด **เข้าสู่ระบบ** ด้วยบัญชี Google
3. ไปที่ **โปรไฟล์** กรอกที่อยู่และเบอร์โทรศัพท์ แล้วกดบันทึก
4. ไปที่ **สั่งซื้อ** เลือกหมวด กดที่เมนูเพื่อดูรายละเอียด แล้วกด **+ ใส่ตะกร้า**
5. ไปที่ **ตะกร้า** ปรับจำนวน ใส่โค้ดส่วนลด แล้วกด **เลือกวิธีชำระเงิน**
6. เลือกวิธีชำระเงิน
   - **พร้อมเพย์:** สแกน QR โอนตามยอด แล้วกดยืนยัน
   - **บัตร:** กรอกข้อมูลบัตร แล้วกดชำระเงิน
   - **เก็บเงินปลายทาง:** กดยืนยันสั่งซื้อ
7. ระบบแสดงหน้า **การชำระเงินเสร็จสิ้น** พร้อมหมายเลขคำสั่งซื้อ
8. ไปที่ **รีวิว** เขียนรีวิวให้ร้านได้

### สำหรับเจ้าของร้าน
ใส่อีเมล Google ของเจ้าของร้านใน `NEXT_PUBLIC_ADMIN_EMAIL=` เมื่อเข้าสู่ระบบด้วยอีเมลนี้ จะเห็นปุ่ม **ลบ** ที่รีวิวที่ลูกค้าเขียน

## Deploy บน Vercel
1. push โปรเจกต์ขึ้น GitHub
2. ที่ [vercel.com](https://vercel.com) กด **Add New → Project** แล้วเลือก repo นี้
3. ใส่ Environment Variables ทั้งหมดจาก `.env.local`
4. ใน Google Cloud Console เพิ่ม redirect URI ใหม่ `https://<โดเมนของคุณ>.vercel.app/api/auth/callback/google`
5. ต้องการเก็บรีวิวถาวร ให้ไปที่ Vercel → **Storage → Marketplace → Upstash Redis** แล้วเชื่อมกับโปรเจกต์

## โครงสร้างโปรเจกต์
```
src/
├─ app/
│  ├─ page.tsx            หน้าแรก
│  ├─ order/              สั่งซื้อ + รายละเอียดเมนู
│  ├─ coupons/            โค้ดส่วนลด
│  ├─ reviews/            รีวิว
│  ├─ cart/               ตะกร้า → ชำระเงิน
│  ├─ success/            ชำระเงินเสร็จสิ้น
│  ├─ profile/            โปรไฟล์
│  ├─ login/              เข้าสู่ระบบ
│  └─ api/                menu, orders, reviews, auth
├─ components/            Navbar, Footer, Providers, Dialog ฯลฯ
├─ lib/                   ฟังก์ชันช่วย (ราคา, แปลภาษา)
├─ auth.ts                ตั้งค่า Auth.js
└─ middleware.ts          บังคับเข้าสู่ระบบก่อนเข้าบางหน้า
```

## ข้อจำกัดของเวอร์ชันปัจจุบัน
- **การชำระเงินด้วยบัตร** เป็นเพียงฟอร์มตัวอย่าง ยังไม่ได้ตัดเงินจริง และระบบไม่ส่งเลขบัตรไปเซิร์ฟเวอร์ ถ้าจะรับบัตรจริงต้องต่อผู้ให้บริการ เช่น Omise หรือ Stripe
- **พร้อมเพย์** ใช้การกดยืนยันโดยลูกค้า ระบบยังไม่ตรวจสอบว่าเงินเข้าจริง
- **คำสั่งซื้อ** ยังไม่ถูกบันทึกลงฐานข้อมูล
- **ราคาเมนู** เป็นราคาสมมติที่คำนวณจากรหัสเมนู
- **ชื่อเมนูภาษาไทย** เป็นการแปลด้วยเครื่อง แก้ชื่อเองได้ที่ `TH_OVERRIDE` ในไฟล์ `src/lib/menu.ts`
